The Brain / Capabilities / Silence detection

SENSE

It notices when nothing has happened
for too long.

A thread quiet for nine days. An approval nobody chased. A task created on Monday and never picked up. No system records these, so WorkElate Chief, the Brain, works them out from the last thing that did happen, and quiet becomes something that can be sorted and judged.

What changes on Monday: the thing nobody remembered to chase is on the list, and the hundreds of quiet things that do not matter are not.

What it looks like on a Tuesday

Three quiet things, and only one is raised

07:40

An approval passes eleven days with no event

Crosses mail and documents. The last event is the request itself. No reply, no view, no status change since. Eleven days is not a configured threshold, it is simply how long it has been.

07:41

Two other quiet records are found and dropped

Crosses the project tool and chat. An undated backlog task and a thread about a decision closed elsewhere. Both silent, neither worth a morning, so neither is raised.

07:43

One item, with the chase already written

Crosses mail. The approval blocks two dated tasks and a Thursday review. It is raised once, with a drafted reply. Sending stops for a person, so a person clicks.

How it works

Three mechanisms

01

Absence is derived from the last event, never from a reminder

Every record carries a last-touched time as a consequence of ordinary use. Quiet is the gap between that and now. Nobody sets a follow-up date, and there is no reminder to forget.

02

A gap is only a candidate, and most candidates die

A quiet record is raised only when the silence has a consequence: something dated depends on it, somebody outside is waiting, a commitment references it. That is judged against your written policy.

03

The same quiet thing is raised once, not daily

Silence grows every hour, so an unguarded version nags forever. Each item is raised once and updated in place, inside a cap of 40 interruptions an hour company-wide and 5 per person.

What it is not

Three honest limits

It cannot see silence in a system it is not connected to.

It does not know a quiet thread was settled over lunch. A person says so once and the correction is held.

It is not a productivity monitor. It measures records, not humans.
