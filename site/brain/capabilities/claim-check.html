What it looks like when it fires

An update that matched nothing, narrated as done

01

Success reported, nothing modified

The filter used an account identifier superseded by a merge. The store answers: operation succeeded, zero records changed.

02

The draft says the date moved

The reasoning step saw a success flag and a request to move a date, and wrote the sentence they imply.

03

The sentence loses to the data

The payload carries a modified count of zero, so the reply says the update matched no records and names the identifier.

How it works

A cheap judge, a narrow question, an exit

01

Payloads cannot be persuaded

The evidence is the structured result of the calls that ran. Text the AI read earlier, including inbound mail, is not evidence.

02

Abstaining is a first-class answer

The judge answers in a fixed shape and may say it cannot tell, so it never invents a verdict on ambiguous evidence.

03

One re-draft, then a plain correction

The AI gets one attempt holding the data. If that still misses, code writes a plain correction. Nothing ships silently.

What it is not

Three honest limits

It does not grade whether the action was wise.

It runs only when something changed and completion is claimed.

A judge can be wrong; it errs towards letting truth through.
