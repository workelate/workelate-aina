The Brain / Capabilities / The twelfth application

CONNECT

The twelfth system has to cost
what the second one cost.

Integration platforms are pleasant in year one and unmaintainable in year three, because somewhere a list has one row per connected system and a person has to remember it. The Brain is reviewed against one question: a twelfth application ships tomorrow, what must be hand-written in the Brain. The acceptable answer is nothing.

What changes on Monday: bringing a new system into a running installation is priced on that system’s own declaration, not on reopening the judgment layer. Month nine looks like month two.

What it looks like when it fires

A new system, and nothing in the Brain to edit

01

The application declares itself

It states the objects it owns, the events it emits and the addresses its verbs resolve to. That is the application being built, and it is the right place for the cost.

02

The Brain reads the declaration, and holds no list

There is no table of applications to add a row to. Every surface that needs to know what exists reads the declarations, so there is nothing to forget.

03

It works on day one, or it fails loudly

An application that declares itself correctly needs no welcome. One the Brain cannot serve says so through the refusal path, never the nearest half-fitting action.

How it works

Declaration over enumeration, in three places

01

Applications declare their own events

Each application announces what happened in its own words. The Brain reads those declarations and keeps no list of which applications exist.

02

The vocabulary can shrink, never grow

15 verbs resolve to 287 actions across the Brain’s own 12 surfaces and 190 business objects, and the verb count is only allowed to fall. Reach grows as addresses under existing verbs.

03

A fact with two sources of truth is treated as a bug

If a property can be derived, it is derived; a hand-kept mirror drifts silently in whichever direction nobody tests. Danger is derived too: a destructive verb gates every new address under it.

What it is not

Three honest limits

It is not a claim that connecting a system is free. The application’s own declaration is real work, and on a third-party system that work is the engagement.

It is not fully achieved. Some hand-kept coverage tables remain, tracked as debt rather than described as design.

The 12 surfaces are the Brain’s own applications, not a count of your systems. What yours emit is what the Brain can see.
