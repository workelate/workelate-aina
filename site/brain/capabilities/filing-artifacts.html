What it looks like on a Tuesday

A review deck nobody goes looking for

10:02

Source material is read from the folder

The folder already holds the signed brief, the tracking sheet, last quarter’s deck and the thread where scope moved in July.

10:04

The deck is created into the folder

10:12 · a person confirms

Sharing outward waits for a click

Creating and filing are ordinary writes. Sharing outward stops for a person, so the deck sits complete until the director approves.

How it works

Three mechanisms

01

The folder is the container

Nothing is merged into one store. A folder holds a mixed set; every item opens in the app that understands it.

02

Filing makes later recall cheap

A question about the client reads one place instead of five searches merged: answering about an engagement, not finding a document.

03

Everything filed stays inside your data

The folder a file lands in follows from who signed in, never from a value the AI wrote.

What it is not

Three honest limits

It files what it creates; it does not reorganise old drives.

It covers the apps that have wired filing in.

It cannot file into a structure that does not exist.
