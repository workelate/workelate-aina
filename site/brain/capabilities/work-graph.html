The Brain / Capabilities / Work graph

RECALL

Ask about the client and get the client,
not ten documents that mention them.

Your systems each hold a true fragment of the same engagement, and none holds the relation between the fragments. The work graph is that relation, written down: a typed link between two real things, stored once, so a question about a client returns the client.

What changes on Monday: where is the Northbeam renewal is answered in three sentences from the relations, and nobody opened five tabs.

What it looks like on a Tuesday

One question, answered from the relations rather than the words

09:10

The name resolves to one node, not a search term

Crosses the Brain’s memory. Northbeam is a client node with edges already attached, so the answer starts from an identity rather than a guess about spelling.

09:10

The neighbourhood comes back with the edges attached

Crosses documents, mail, tasks and the calendar. A renewal, its contract, a thread about it, two dependent tasks and Thursday’s review. Without the relations these are six hits with a name in common.

09:11

The blocker is named because something points at it

Crosses documents and tasks. One task depends on a clause still open in the contract. Neither system knew the other cared. The edge turns two green statuses into one honest red.

How it works

Edges are written by the work, not typed by a person

01

Applications declare what happened, and the graph records it

Each declared event can carry the edge it implies, so links appear because work happened. Where an engagement connects a third-party system, the Brain reads what that system emits through the connection.

02

A graph answers what a ranked list cannot

A search index scores documents against words, and belonging is not a word in either of them. The graph stores belonging as a typed fact, so the question becomes what is connected, and how.

03

The vocabulary is small on purpose, and fenced

A large vocabulary drifts into a second stale database. The graph and the memory share one, and every edge names its organization before it is stored, so reasoning cannot widen its own view.

What it is not

Three honest limits

It is not a new system of record. Edges point back at rows that still live where they always lived.

It does not know about work never written down anywhere.

It is not complete on day one. The graph is as dense as the systems connected to it.
