The Brain, changelog

What shipped, and when.

Every entry on this page carries a date, and a date means the work runs on a real stack rather than existing in a plan. If a capability is not dated here, it has not shipped: it is on the roadmap under building now or next, and we will say so plainly if you ask on a call. Newest first.

Entries

Newest first.

11 September 2026Mail

Mail in the loop

  • The Brain reads a mail thread in full context and drafts the reply with the surrounding work attached.
  • A reply already knows the open items and what changed since the last exchange, so you edit a draft instead of reconstructing history.
11 September 2026Files

The folder is the container

  • One folder holds a client’s documents, sheets, decks, forms and boards together. The applications that have declared how they file are the ones this covers today.
  • A question about that client reads the whole folder. Nothing was moved or migrated.
10 September 2026Decks

Deck registers and folder sources

  • A deck can be built from the files in a folder, so a review starts from the client's actual material.
  • The numbers on a slide come from the source that owns them, not from a summary, which is where figures drift.
6 September 2026Sense

Signals running continuously

  • Connected applications emit their work signals continuously, so the morning briefing reflects this morning rather than an older picture.
  • Invisible when it works, which is why it is dated here.
UndatedStanding

Standing capability

  • The work graph, and the ranked Start my day briefing with a reason line and a blocker line on each item.
  • Three checks before anyone is interrupted, rate limited so the same item never raises itself twice.
  • 15 verbs resolving to 287 actions across the Brain’s own 12 surfaces, 71 of them gated on a human yes.
  • A write re-read before it is believed, the sentence checked against what the tools returned, and honest refusal. All of it predates this log.
