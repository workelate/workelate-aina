11 September 2026Mail

Mail replies drafted with the context attached

  • The Brain reads a mail thread in context and drafts the reply with the open items and the surrounding work attached.

The folder is the container

  • One folder holds a client’s documents, sheets, decks, forms and boards, and a question about that client reads the whole folder. Not yet every application.

Deck registers and folder sources

  • A deck can be built from the files in a folder, and each number on a slide comes from the source that owns it.
