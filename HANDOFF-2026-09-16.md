## Generators (run these, never hand-edit their output)

Order matters. After any page change:

    node scripts/gencapindex.mjs   # capability index rows, derived from the pages
    node scripts/genchrome.mjs     # nav + footer per zone, into NAV/FOOTER markers
    node scripts/genseo.mjs --modified=YYYY-MM-DD   # BreadcrumbList, Organization, og/twitter, into SEO markers
    node scripts/gensitemap.mjs    # sitemap.xml + robots.txt, derived from site/
    node scripts/gencorpus.mjs     # the /studio assistant's corpus (reads data/cases.json)
    npm run verify                 # the gate; must be green before a PR

Studio pages that are generated: work.html (genwork), case-studies/*
(gencases), systems/* (gensystems), the hero strip on studio/index
(genbreadth). Edit the template in the script, then re-run it.

Product mockup plates: scripts/genbrain.mjs (4 dark plates). Live work
graph: site/js/workgraph.js (real object types and edge writers from the
backend; do not add nodes that are not real types).

## Rules that bind

1. IP stays internal (founder, 2026-09-12). Public pages carry outcomes and
   the public number set only: 15 verbs, 287 actions, 12 application
   surfaces (only on /brain/proof), 71 confirm-gated, 40 per organization
   and 5 per person per hour, RockProsUSA receipts (13 sites, 38%, 2,140
   invoices, 11,200 hours, first twelve months), $30K to $100K, the 2-week
   Sprint, 34 / 9 / 374. Never a commit sha, file / model / emit / identity-field
   / evaluation count, module name, or "measured at" attribution. The
   measurement and the long form live in `data/brain-facts.md` and
   `data/brain-reading-pack.md`; both are gitignored (this repo is PUBLIC).
2. Grounded only. No invented numbers, quotes, logos, ratings, certifications.
   Vendor claims on compare pages come from the vendor's own public pages,
   cited in the page's srcnote; unknowns are written as "not documented".
3. Copy: one h1 that is a plain sentence, lede one sentence, a tile carries
   one line, a card one sentence, no em dashes, no "enforced", no
   "agentic" for ourselves, the banned list in scripts/verify.mjs
   (audit trail, auditable, every action logged, contact us, ...). The CTA
   phrase "Book a Diagnostic Sprint" must appear on every page (footer
   carries it in the brain zone; the brain hero button is "Book a demo").
4. Images: only the real product (site/img/real/, seeded org only; the
   .gitignore whitelists exactly the published files, everything else in
   that folder stays local) or vendor imagery from the vendor's own site
   (site/img/vendors/SOURCES.md). No mockups of the product.
5. No-JS contract: mega-menu panels and FAQ <details> ship visible/open;
   site/js/nav.js turns them into dropdowns/collapsed. The gate fails on any
   hidden text over 20 chars (an SVG <title> included).
6. Footer parity is asserted per zone; the chrome is generated, never edited
   in a page.
